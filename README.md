# 사운드 제작 — 새 6개 항목

현재 요청 목록은 requests.json의 6개 항목만 사용합니다.
1. 공통 배경음악 1곡
2. 공통 블록 타격음 7개 (모양 구분 없이 랜덤)
3. 선 연결음 1개
4. 마지막 슬로우 효과음 1개
5. 공통 버튼 클릭음 1개
6. 단계 이름 등장 타격음 1개

기존 제출본 및 시험 음원은 현재 보드에서 제거했습니다. 게임의 기존 합성 음악/효과음도 제거하는 작업본입니다. 새 파일을 업로드하고 OGG로 저장하여 제작합니다.
공통 블록 랜덤, 마지막 슬로우, 단계 이름 타격음은 새 게임 연결이 필요한 요청입니다. 보드에서 파일을 저장했다고 게임에 연결 완료된 것은 아닙니다.
음악/선 연결/UI는 기존 슬롯으로 시험할 수 있지만 모든 버튼/새 이벤트 연결은 최종 적용 시 확인합니다.
기존 단계별 팡파르·별도 블록 종류·벽·출발 등은 현재 제작 대상이 아닙니다.
사용자 승인: 2026-11-16. 이번 배포는 6개 제작 요청으로 초기화한 작업본입니다.
