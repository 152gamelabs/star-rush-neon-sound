압축을 풀면 보이는 구성

처음 한 번 CONNECT-GITHUB.cmd로 로그인하고, SoundBoard.exe를 실행하세요.
압축을 푼 폴더/
├─ CONNECT-GITHUB.cmd   ← 최초 로그인
├─ SoundBoard.exe       ← 작업실 실행
├─ START-HERE.html      ← 지금 보는 안내
├─ Sound/               ← 요청·소리 작업
├─ Game/                ← 게임 실행판
├─ board/               ← 사운드보드
└─ runtime/             ← 필요한 도구

나머지 설정·라이선스 파일도 같은 폴더에 둡니다.

작업 저장소가 준비됐어요. 152gamelabs/star-rush-neon-sound는 비공개입니다. 초대를 수락한 뒤 CONNECT-GITHUB.cmd로 본인 계정에 로그인하세요. ZIP에는 같은 Git 이력이 포함되며, 로그인 정보는 각자의 PC에서 관리합니다.

게임 코드를 바꾸면?

개발 담당자가 Unity에서 수정하고 다시 빌드한 실행판을 전달합니다. 사운드보드의 Git은 Sound 작업 폴더를 공유합니다. 개인 진행 기록은 각 PC에 따로 남습니다.

GitHub 연결 전에는?

보드의 작업 내보내기로 소리 작업 ZIP을 보내도 됩니다. 받은 쪽은 제출본을 확인해 합칩니다. 게임 연결 예정인 요청은 소리 제작·저장까지 가능하며 실제 연결은 개발 담당자가 추가합니다.
