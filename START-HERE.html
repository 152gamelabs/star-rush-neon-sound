# Star Rush Neon 사운드보드 — 6개 요청 / 녹화 영상 포함

1. SoundBoard.exe 실행. Unity 설치는 필요 없습니다.
2. 기존 작업 폴더를 연결하고 '최신 작업 받기'로 목록을 갱신합니다.
3. 각 요청의 '무음 영상 보기' 또는 '크게 보기'로 참고 연출을 확인합니다.
4. 파일 넣기 → OGG로 저장 → 장면으로 들어보기 → 이 소리 보내기 순서로 작업합니다.
5. 블록 타격음은 7개 파일을 넣고 랜덤 재생을 선택합니다. 나머지는 각각 1개입니다.

요청: 공통 BGM 1곡 / 블록 타격 7개 / 선 연결 1개 / 마지막 슬로우 1개 / UI 클릭 1개 / 단계 이름 등장 1개.
마지막 슬로우와 단계 이름 요청은 같은 연쇄 영상에서 각각 다른 타이밍을 참고합니다.
영상은 최신 PC 게임 렌더러로 녹화한 무음 테스트 장면입니다.

기존 종류별 음원은 이번 제작 목록에서 제외했습니다. 새 공통 블록·마지막 슬로우·단계 이름 슬롯은 게임 연결 예정이며, 파일 전송은 게임 최종 적용과 다릅니다.
기존 작업이 있어 받기가 막히면 강제 초기화하지 말고 작업 파일을 별도 보관한 뒤 문의해 주세요.
새 ZIP은 새 프로그램 폴더에 풀어 주세요. 기존 작업 폴더나 저장 파일을 덮어쓰지 마세요.
GitHub 인증이 필요한 경우 YookJungYun 계정으로 로그인하고 CONNECT-GITHUB.cmd 안내를 따르세요.
